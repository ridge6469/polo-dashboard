# polo-dashboard

Polo 后台账号用量看板。网页放在 GitHub Pages，数据在你自己的服务器上，登录后才能读取。

- 看板地址：https://ridge6469.github.io/polo-dashboard/
- 网页代码：`docs/`（纯静态 HTML/JS，无第三方依赖）

## 数据从哪来

```
GitHub Pages 网页 ──HTTPS + 看板密码──▶ 服务器登录网关 ──▶ 本机只读接口 ──▶ 定时采集的快照
```

- 服务器每约 10 分钟用无头浏览器读取一次 Polo 后台，生成快照。
- 网页只读取快照，不会触发后台刷新，也没有任何修改后台的功能。
- 网关只接受来自 `https://ridge6469.github.io` 的跨域请求；登录失败过多会被暂时拒绝。
- 登录令牌只保存在当前浏览器标签页（关闭标签页即失效），有效期 12 小时。

## 修改看板密码

SSH 登录服务器后运行：

```bash
polo-dashboard-passwd
```

按提示输入两次新密码（至少 12 位）。修改后所有已登录的页面都需要重新登录。

## 不要提交到本仓库

本仓库是公开的。以下内容一律不要提交：

- 网站账号密码、服务器密码、看板密码、接口令牌
- 账号用量快照、导出的 CSV/JSON 数据
- Cookie、浏览器配置目录、`.env` 等本地凭据文件
